# 首次开源隐私检查

公开范围为源码、项目文档、许可、图标和虚构示例截图。Windows 下载包仅包含应用及所需许可。

首次发布采用以下处理：

- 本地草稿、照片、模型设置和系统加密后的密钥留在本机，不进入 Git。
- 排除下载缓存、浏览器会话、崩溃文件、测试结果与 PDF 排版产物；仅保留端到端测试需要的虚构头像。
- 移除验证脚本中的本机用户名和文档中的本机绝对路径。
- 使用全新的提交历史；提交作者与提交者为 `Resume Workshop contributors`，邮箱为 `contributors@users.noreply.github.com`，不采用本机 Git 的姓名或真实邮箱。
- MIT 版权署名为项目贡献者；保留第三方依赖本身依法需要的署名与许可。
- 检查源码、文档、锁文件、提交内容与打包内容中的个人信息和常见密钥格式。
- 人工检查公开截图；其中姓名、学校、联系方式与经历均来自标明“虚构”的示例。

公开仓库归属的 GitHub 用户名会出现在仓库地址中，Release 也显示发布账号。这些平台信息会公开；项目文件与 Git 提交不使用私人姓名、邮箱或本机账户路径。

虚构示例与测试中的 `example.com` 邮箱、示例电话号码及 `fake-test` 密钥均为测试占位内容。第三方许可中的其他作者信息不属于项目所有者的个人信息，保留原文。

应用运行后，用户自己填写的资料会保存在本地。JSON 备份含简历与照片；上传 Issues、截图或后续提交前需自行脱敏。AI 使用的数据范围详见 [使用教程](USER_GUIDE.md)。

以上记录描述首次发布的检查范围。它不能代替对后续新增文件、截图、备份和提交的检查。
