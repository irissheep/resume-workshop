- 系统：Microsoft Windows 11 专业版，10.0.26200，64 位。

- TypeScript 检查通过；生产 build 和 Windows NSIS/ZIP 打包通过。
- Vitest：2 个测试文件，40 项通过。覆盖字段/版本/ID/导入大小、事实与范围保护、非法模型输出、隐私最小化、保存次序/失败/损坏文件、密钥与错误分类。
- 打包版：原有 5 个桌面场景完整运行通过；随后增强的 AI 场景与新增展示场景分别复验通过，共 6 个场景均已通过。
- 打包版运行目标为 release/win-unpacked/Resume Workshop.exe。测试使用带中文和空格的独立数据目录，未依赖开发服务器。
- 桌面测试实际启动 Electron、读写 JSON、执行 printToPDF、显示原生 PDF 查看器、使用本机 HTTP 服务器和 Windows safeStorage。
