# 使用教程

简历工坊（Resume Workshop）是 Windows x64 桌面应用。你可以全手动制作简历，也可以配置自己的模型服务帮助整理文案。

## 1. 安装并打开

从 [v0.1.0 下载页](https://github.com/irissheep/resume-workshop/releases/tag/v0.1.0) 选择：

- **安装版**：下载 `Resume-Workshop-0.1.0-x64.exe`，双击并按向导安装，然后打开“Resume Workshop”。
- **ZIP 版**：下载 `Resume-Workshop-0.1.0-x64.zip`，完整解压后双击 `Resume Workshop.exe`；不要直接在压缩包里运行。

使用安装包或 ZIP 不需要 Node.js、Python 或 Git。当前安装包未进行代码签名。

## 2. 先做一份手动简历

1. 打开“我的简历”，点击“＋ 新建简历”。也可先打开“虚构示例”熟悉界面。
2. 在“基本资料”填写姓名、联系方式、城市和求职意向；照片与作品链接可选。
3. 在“教育背景”添加学校、专业、起止时间等信息。GPA 同时填写成绩与满分。
4. 在“项目经历”“实习 / 工作”“校园经历”添加对应经历。
5. 每条经历中，“原始关键词 / 口语描述”用于记录素材，“已确认事实”用于记录本人职责和可核对的成果；**最终显示在 PDF 中的是“正式描述条目”**。手动填写正式描述即可，无需 API Key。
6. 按需填写“个人简介”“荣誉奖项”“技能与证书”。没有内容的模块可以隐藏，之后仍能找回；删除会清除对应内容。
7. 等顶部状态显示“已保存”。应用会自动保存，正常关闭后再次打开可以继续编辑。

写描述时可按“做了什么 → 本人负责什么 → 使用了什么 → 有哪些可证实结果”组织，不填自己无法确认的数据。

## 3. 选模板并导出 PDF

1. 在右侧选择“简洁单栏”“商务单栏”或“校园双栏”，调整主题色、照片开关与预览缩放。
2. 使用左侧模块的上移、下移与隐藏按钮调整展示。校园双栏的排序在各栏内生效。
3. 点击“PDF 分页预览”，检查实际页数、文字、日期、照片与分页。
4. 点击“保存此 PDF”，或返回工作台点击“导出 PDF”，选择保存位置。

编辑区的预览帮助查看样式，实际分页以 PDF 分页预览为准。若提示资料有误，按提示修正日期、GPA 或链接后重试。

## 4. 可选：接入 AI

1. 打开左侧“模型设置”。
2. 填写模型服务地址、模型名称（服务商的模型 ID）与自己的 API Key。模型配置名称可选。
3. 地址填写聊天接口的前缀：应用会追加 `/chat/completions`，不会自动添加 `/v1`，也不要填已经带有 `/chat/completions` 的完整地址。
4. 例如 DeepSeek 的前缀可填 `https://api.deepseek.com`；当前模型 ID 以 [服务商官方文档](https://api-docs.deepseek.com/zh-cn/) 或控制台为准。其他兼容服务按各自文档填写。
5. 按需勾选“使用系统加密记住密钥”，点击“保存并测试连接”。看到连接成功后返回编辑工作台。
6. 填好经历素材与事实，点击“生成简历文案”。在建议面板核对、修改，然后逐项采用或采用全部待确认文案。
7. 某条经历可以使用“帮我补充经历”“优化表达”“精简内容”或“突出个人贡献”。求职意向与招聘描述填好后，可使用“按岗位调整”。

连接测试可能消耗少量额度，AI 请求费用由你的模型服务商收取。远程地址必须使用 HTTPS，本机回环地址可以使用 HTTP。无需 AI 时直接手动编辑即可。

AI 请求会省略基本资料中的姓名、电话、邮箱、城市、作品链接和照片，但**你在经历、已确认事实或招聘描述中自行输入的信息仍会发送给模型服务**。请先检查这些文本。建议文案必须人工核对；修改资料后，旧建议可能需要重新生成。

## 5. 备份、恢复与多岗位版本

- 工作台点击“JSON 备份”，保存当前简历的可恢复备份，包含照片与原始素材，不包含模型密钥。
- 在“我的简历”点击“导入备份”，选择本应用导出的 JSON；恢复为独立的新简历，不覆盖原稿。
- 在简历卡片点击“复制”，为不同岗位制作独立版本，再重命名便于区分。
- PDF 用于投递；JSON 用于继续编辑。建议同时保存两种文件。

在“帮助与关于”可查看实际本地草稿目录。备份可能包含你的个人资料，请保存在自己的位置，不要提交到公开仓库或问题反馈中。

## 6. 从源码运行

需要 Windows x64、Git、Node.js 24.11.1 和 npm。在 PowerShell 中运行：

```powershell
git clone https://github.com/irissheep/resume-workshop.git
cd resume-workshop
.\scripts\npm.ps1 ci
.\scripts\npm.ps1 run prepare:electron
.\scripts\npm.ps1 run dev
```

如果 PowerShell 因执行策略阻止脚本，可只为当前窗口设置后重试：

```powershell
Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass
```

第一次安装依赖需要联网。依赖、缓存与开发数据使用项目内的 `node_modules/`、`.cache/` 和 `.local-data/`。首次启动自动创建虚构示例。

验证与打包命令见 [README](../README.md)；打包后安装包在 `release/`。

## 7. 常见问题

| 现象 | 处理 |
|---|---|
| 没有 API Key | 手动填写正式描述，仍可保存和导出 PDF。 |
| 401 / 403 | 在模型设置检查密钥及模型访问权限。 |
| 404 | 检查前缀地址、是否重复添加接口路径，以及模型 ID。 |
| 429 | 在服务商控制台检查额度与限流，再主动重试。 |
| 请求超时 | 检查网络与模型服务状态；草稿仍在，可以取消后重试。 |
| 只填关键词，PDF 没有经历正文 | 补充“正式描述条目”，或核对并采用 AI 建议。 |
| 显示保存失败 | 保持窗口打开，先导出 JSON 备份；检查数据目录权限与磁盘，再点“重试保存”。 |
| 草稿损坏 | 先复制保留原文件，再从已有 JSON 备份恢复；不要直接覆盖损坏原稿。 |

请通过 [GitHub Issues](https://github.com/irissheep/resume-workshop/issues) 反馈，并使用虚构数据复现；不要附 API Key、真实简历、个人照片或包含用户名的日志。
